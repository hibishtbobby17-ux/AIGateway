Core Architecture

Built for Production AI Scale

Stateless Go data plane proxies decoupled from Next.js control plane for maximum throughput, low tail latency, and strict multi-tenant isolation.

Universal Multi-Cloud LLM Gateway

Drop-in OpenAI-compatible router supporting Azure OpenAI, AWS Bedrock, Anthropic Claude, and OpenAI with automatic latency failover, circuit breakers, and FinOps token attribution.

OpenAI SDK AWS Bedrock Azure Anthropic

Model Context Protocol (MCP) Aggregator

Consolidate dozens of downstream MCP tool servers behind a unified endpoint with schema virtualization, namespace prefixing, and SSRF-safe egress controls for Cursor and Claude Desktop.

MCP JSON-RPC Claude Desktop Cursor SSRF Guard

Agent-to-Agent (A2A) Protocol

Standardized agent discovery using Agent Cards, durable task state machines, Server-Sent Events (SSE) status streaming, and W3C distributed trace propagation across autonomous agent swarms.

Agent Cards Task State Machine SSE Streams

Enterprise IAM & Zero-Trust Security

Native OAuth 2.1 PKCE S256 authorization server, external IdP federation (Okta, Entra ID, Auth0), AES-256-GCM encrypted credential vault, and fail-closed token revocation checks.

OAuth 2.1 PKCE RBAC & ABAC AES-256-GCM

AI Guardrails & PII Redaction

Real-time regex and token masking for SSNs, credit cards, emails, and cloud API keys. Automatically stops prompt injection attempts and filters sensitive payloads before upstream dispatch.

PII Masking Prompt Defense Payload Sanitizer

Pluggable Telemetry Sinks

Store high-velocity traces and audit logs in ClickHouse OLAP, AWS OpenSearch, direct to AWS S3 Data Lake (Parquet), or export directly to OpenTelemetry (OTLP) collectors.

ClickHouse OpenSearch S3 Parquet OTLP APM
System Topology

Decoupled Control & Data Planes

Designed to run in hybrid multi-cloud environments, from local developer laptops to large-scale Kubernetes clusters.

1. Consumer Ingress
OpenAI SDK / Python / TS Standard /v1/chat/completions
Claude Desktop & Cursor Model Context Protocol (SSE / StdIO)
Autonomous Agents Agent-to-Agent (A2A) tasks
2. AIGateway Data Plane
OAuth 2.1 PKCE & Rate Limiter In-Memory Redis cache validation
Guardrail Engine & PII Redactor Zero-trust outbound dialer (SSRF safe)
Dynamic Failover & Provider Load Balancer Latency circuit breaker routing
3. Providers & Telemetry
LLM Cloud Providers Azure OpenAI, AWS Bedrock, Anthropic
MCP Tool Microservices PostgreSQL, GitHub, Slack, Jira Tools
Telemetry Sinks ClickHouse, OpenSearch, S3, OTLP
Developer Experience

Zero Code Changes Required

Works seamlessly with existing SDKs by updating just the base URL.

import os
from openai import OpenAI

# Direct standard OpenAI SDK to your secure AI Gateway instance
client = OpenAI(
    base_url="http://localhost:8080/api/llm/production-models/v1",
    api_key=os.environ.get("GATEWAY_API_KEY", "ak_live_enterprise_secret")
)

# Gateway handles token metering, PII masking, and routes to Azure or Bedrock
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a secure corporate assistant."},
        {"role": "user", "content": "Analyze our infrastructure quarterly billing metrics."}
    ],
    temperature=0.2
)

print(response.choices[0].message.content)
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:8080/api/llm/production-models/v1',
  apiKey: process.env.GATEWAY_API_KEY || 'ak_live_enterprise_secret',
});

async function main() {
  const completion = await openai.chat.completions.create({
    model: 'claude-3-5-sonnet', // Transparently transformed and routed to Bedrock or Anthropic
    messages: [{ role: 'user', content: 'Generate security audit checklist' }],
  });
  console.log(completion.choices[0].message.content);
}

main();
